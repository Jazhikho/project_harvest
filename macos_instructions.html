🌽 Project Harvest - macOS Installation

⚠️ IMPORTANT FOR MAC USERS
Project Harvest is not code-signed, so macOS Gatekeeper will block it. This is normal for indie/student games and the app is safe to run. Follow one of the methods below to bypass this security feature.

Choose Your Method

EASIEST Method 1: Right-Click Open

  1. Download and extract ProjectHarvest.zip
  2. Right-click (or Control+Click) on ProjectHarvest.app
  3. Select "Open" from the context menu
  4. Click "Open" when prompted about the unidentified developer
  5. The game will launch! macOS will remember your choice for future launches.

This is the recommended method for most users.

RECOMMENDED Method 2: System Settings

  1. Try to open the app normally (it will be blocked)
  2. Open System Settings → Privacy & Security
  3. Scroll to the Security section
  4. Click "Open Anyway" next to the ProjectHarvest message
  5. Confirm by clicking "Open"

Works on macOS Ventura 13.0 and later.

ADVANCED Method 3: Terminal Command

For users comfortable with Terminal:

  1. Open Terminal (Applications → Utilities → Terminal)
  2. Navigate to the download location:
    cd ~/Downloads
  3. Remove the quarantine flag:
    xattr -cr ProjectHarvest.app
  4. Open the app normally from Finder

🔧 Troubleshooting

"The application is damaged and can't be opened"

This happens when macOS quarantines the download. Run this Terminal command:

xattr -cr ProjectHarvest.app

App opens then immediately closes

  1. Move the app to your /Applications folder
  2. Make sure you meet the system requirements (see below)
  3. Check Console.app for error messages

💻 System Requirements

  • OS: macOS 10.12 (Sierra) or later (11.0+ for Apple Silicon)
  • Processor: Intel Core i5 or Apple Silicon M1+
  • Memory: 4 GB RAM (8 GB recommended)
  • Graphics: Metal-compatible GPU
  • Storage: 2 GB available space

❓ Why Isn't This Signed?

Apple requires developers to pay $99/year for a Developer account and submit apps for notarization. As a student/portfolio project, Project Harvest is distributed unsigned to keep it free and accessible to everyone. The game is completely safe to run.

You can review the source code on GitHub or scan the download with your antivirus software if you have any concerns.

🎮 Ready to Play!

Once you've successfully opened the game, the first launch may take 30-60 seconds while macOS verifies the app. Future launches will be much faster.
