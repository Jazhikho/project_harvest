                            QUICK START GUIDE
================================================================================

METHOD 1 - RIGHT-CLICK TO OPEN (Easiest)
----------------------------------------
1. RIGHT-CLICK (or Control+Click) on "ProjectHarvest.app"
2. Select "Open" from the menu
3. Click "Open" when warned about unidentified developer
4. Done! Future launches will work normally.

METHOD 2 - TERMINAL COMMAND (Fast)
-----------------------------------
1. Open Terminal
2. Type: cd ~/Downloads
3. Type: xattr -cr ProjectHarvest.app
4. Open the app normally

METHOD 3 - SYSTEM SETTINGS
---------------------------
1. Try to open the app (it will be blocked)
2. Go to System Settings → Privacy & Security
3. Click "Open Anyway" next to the ProjectHarvest message
4. Confirm
